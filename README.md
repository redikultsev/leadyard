# leadyard

An open framework for the daily loop of a developer and a tech lead working with coding agents.

- **"Done" is evidence, not a claim.** A task has a level from 0 to 5, computed by a program
  from artifacts with links. Evidence goes stale when the covered files change.
- **Rules that matter are enforced,** by hooks, git and the server, and verified by probes.
- **A human decides** the verdict, the merge and the deploy. Everything else follows the risk
  class of the task.
- **Any agent.** Certified: Claude Code, Codex, Cursor. State lives in files in git.

Status: **design phase.** Nothing here is usable yet. Read the [design](docs/design.md) and the
[decisions](docs/decisions.md). Versions before 1.0 follow the `0.y.z` rule: anything may change.

`leadyard` is a working name.
